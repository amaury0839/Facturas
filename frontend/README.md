# Frontend Facturación 606/607

SPA creada con React + Vite para interactuar con el backend FastAPI.

## Scripts

```bash
cd frontend
npm install
npm run dev     # levanta en http://localhost:5173
npm run build   # build de producción
npm run preview # previsualización del build
```

Configura la variable `VITE_API_BASE_URL` para apuntar al backend (por defecto `http://localhost:8000`).
